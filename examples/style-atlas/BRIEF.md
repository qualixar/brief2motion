# Brief: Style atlas

A reference page that shows one small product page fragment (a nav, a headline, two buttons, a card with a number and a field) in every visual style the skill knows, so the styles can be compared side by side and measured.
What moves: only each style's own hover and press behaviour. Two styles have a slow background drift or a short burst, and both stop with reduced motion on.
Look: the page itself is plain so the specimens are the only styled things.
Stack: plain HTML and CSS, generated from the style data.
Done when: every specimen passes the text contrast check, every control has a visible focus ring and a 24 px target, and the page is generated from references/styles.json with nothing edited by hand.
