About

Noor draws type for print and signage from a small studio above a ferry terminal. Commissions start with a paragraph of real text from the client, set badly, and a conversation about why it is hard to read.

Noor is not a real person. The posters are SVG files written by hand for this example, set in whatever fonts your device already has.
