# Brief: Noor Halvorsen

A portfolio for a type designer with four typefaces. Several pages: an index and one page per typeface.
What moves: page transitions. When I click a poster on the index it grows into the big poster on the project page, and shrinks back when I press Back. On the index, filter and sort buttons rearrange the grid and the cards glide to their new places. Nothing else moves.
Words on the page, exactly: headline "Typefaces for timetables, cookbooks and anything else people read in a hurry."
Images: none supplied. Make a specimen poster for each typeface as SVG.
Look: plain paper and ink; each typeface has one colour of its own. Heavy grotesque type.
Stack: no animation library. It must work as ordinary pages in a browser that has no view transitions.
Done when: the poster morphs between the index and a project page in both directions, the filter leaves the right cards, every page passes the site check, and with reduced motion on the pages simply change.
