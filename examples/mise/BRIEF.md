# Brief: Mise

A page for Mise, a weekly meal planner, with a working demo of the planner in the hero. It is a React app.
What moves: only things that answer what I do. A marker slides between the two tabs. I can drag dinners to reorder them and the others step aside; opening a dinner pushes the rest down. Removing a dinner shrinks it away. In the shopping tab, ticking an item moves it to a "bought" list and the count of things left rolls to its new value on a spring.
Words on the page, exactly: headline "Plan the week. Shop once. Cook what you planned."
Look: pale lilac page, aubergine ink, tomato red for the one thing you can press. Rounded friendly type.
Stack: React with Motion for React (Framer Motion).
Done when: reordering works by dragging and from the keyboard, the shopping count is right after each tick, the page shows the week as a plain list when JavaScript is off, and with reduced motion on the same changes happen at once.
